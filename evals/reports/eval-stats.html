Method

Intervals: Wilson score, 95%. Comparisons: Fisher's exact test, two-sided, on passed and failed attempts. Runs needed: normal approximation, 5% significance, 80% power. Runs on different task sets are never compared. The code changed between runs, so a comparison measures everything that changed, not only the named setting.
